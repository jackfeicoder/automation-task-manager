# 功能说明

## 任务调度

每个任务可选择手动、每日、每周、固定间隔或五段 Cron，并设置独立时区。开启定时后自动计算下一次执行时间；关闭定时后停止后续调度，当前执行由「停止」按钮控制。

全局暂停用于暂停定时触发，已排队任务继续处理。服务恢复时，根据补跑策略对错过的任务最多补跑一次，避免集中重复执行。

## 独立执行与并发

任务在独立进程中执行，单个任务失败不会中断其他任务。全局并发数量控制同时执行的任务数；同一任务最多有一项活动执行，同资源组任务依次运行。

启动任务时固定本次配置。需要修改正在使用的脚本时，先停止相关任务，再通过界面保存修改。

## 执行记录

执行记录展示状态、耗时、尝试次数及日志，并支持停止与重新运行。界面定期更新日志，平台按配置清理过期日志。

业务结果可显示为成功、今日已完成、失败、需要登录或需要处理。允许重试的失败按配置有限重试；脚本应保证重复运行不会产生重复操作。

## 脚本管理

界面支持创建和编辑 Python、JavaScript、PowerShell、Shell 脚本。保存前备份旧版本，Python 脚本同时进行语法检查。

插件目录扫描用于发现新任务，已有任务以网页保存的配置为准。删除任务后，扫描或重启不会自动恢复，可通过新建任务重新添加。

## 配置与运行环境

全局配置包括并发数、默认时区、调度暂停、补跑、重试间隔和日志保留。运行环境页面用于配置本机任务变量并查看配置状态，保存的变量值不回显。

本地配置、登录信息、数据库、日志和浏览器状态与项目源码分开保存。部署与备份方式见 [项目说明](../README.md)。

## WorkBuddy 签到

插件使用本机 WorkBuddy 客户端的登录状态查询签到活动并领取每日积分，以服务端积分结果或明确的今日已签到结果确认完成。

登录过期时在客户端重新登录，再手动运行任务。网络或服务端暂时异常时，可按配置有限重试。客户端接口变更后需要更新插件。
