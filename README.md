# 自动化任务管理平台

通过 Web UI 管理脚本任务：定时开启与关闭、频率设置、单个与批量运行、日志及执行历史。

当前仅创建目录骨架，尚未实现服务、界面和任务脚本。

## 目录

```text
automation/
├── backend/
│   ├── app/
│   │   ├── api/          # 前端调用的任务管理接口
│   │   ├── scheduler/    # 定时调度、时区与补跑策略
│   │   ├── runner/       # 执行队列、独立子进程、超时清理
│   │   └── storage/      # 配置与执行记录的数据库访问
│   └── tests/            # 后端验证
├── frontend/
│   └── src/
│       ├── api/          # 后端接口调用
│       ├── components/   # 公共界面组件
│       └── pages/        # 任务列表、详情、执行记录页面
├── tasks/
│   └── example/          # 示例任务插件，后续放置配置与脚本
├── config/               # 平台配置示例
├── data/
│   ├── profiles/         # 独立浏览器登录状态
│   ├── logs/             # 执行日志
│   └── artifacts/        # 截图及诊断文件
├── docs/                 # 设计与使用文档
└── scripts/              # 启动与维护脚本
```

SQLite 数据库后续保存在 `data/state.db`。`data/` 下的运行数据与登录状态不提交到版本库。

任务插件支持独立启动命令；调度配置统一由平台管理。每次任务执行使用独立进程，某项失败时其余任务继续运行。
